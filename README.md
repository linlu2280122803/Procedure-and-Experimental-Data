# [JND of Auditory Alert Duration in Automated Driving: A Comparison of Earcons and Auditory Icons under Noise and Non-driving Related Tasks] Procedure and Data

This repository contains the complete executable experimental program and the raw experimental data for the paper titled "JND of Auditory Alert Duration in Automated Driving: A Comparison of Earcons and Auditory Icons under Noise and Non-driving Related Tasks, for review purposes.

## Content Description
- **`Procedure/`** folder: Contains the complete executable experimental program (built with Unity) along with all its dependent files.
- **`Experimental Data.xlsx`**: The original experimental data table.
- Other relevant documents.

## Important: Steps to Obtain the Complete File 
Due to the large size of the software packages, this repository uses **Git Large File Storage (LFS)** for file management.
**To run the program locally or to view the complete data, please follow these steps:**

1. **Install the Git LFS tool** (if it is not already installed):
   - Visit https://git-lfs.com to download and install.。
    - Alternatively, execute the following command in the command line: `git lfs install`.

2. **Clone this repository:**
    - Execute the following command in the command line (SSH method is recommended; alternatively, use HTTPS):
    ```bash
    git clone git@github.com:linlu2280122803/Procedure-and-Experimental-Data.git
    ```
    - This command will automatically download all files, including large files managed by Git LFS.

3.  **Running the Program:**
    - Navigate to the cloned folder, locate the executable file (e.g., `AutoDrivingExp_LL3.exe`) in the `Procedure/` directory, and run it.
